<base> tag test

This page's <head> sets <base href="/some/other/path/">, which changes what every relative URL on this page resolves against - including, deliberately, the navigation links a normal page here would have. That's why there's no site nav on this specific page: any relative link below resolves against the <base>, not against this page's own folder.

The link below has no leading slash, so per the HTML spec it must resolve against the <base> href above, i.e. to https://<host>/some/other/path/next-doc.html - not to a file sitting next to this one:

Relative link, resolved against <base>

That target doesn't exist; a correct resolver should still report the fully-resolved URL above rather than https://<host>/test-crawl-website/next-doc.html.
